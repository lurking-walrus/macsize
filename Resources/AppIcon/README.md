# MacSize app icon

| File | What it is |
| --- | --- |
| `AppIcon.icns` | macOS app icon with all ten iconset sizes (16, 32, 128, 256 and 512 pt at @1x and @2x) |
| `AppIcon-1024.png` | 1024 x 1024 master render, for the README, website, and social previews |
| `logo.svg` | Monochrome treemap mark only (`fill="currentColor"`, no background), for the README and website |

All three are generated by `scripts/make-icon.swift` and committed, so a normal build
does not need to run the script.

## Design

A squarified treemap of five tiles (weights 40/24/16/12/8) on a macOS Big Sur-style
rounded square:

- **Body:** the 824 px body from Apple's icon grid, centred on a 1024 px canvas, with a
  185 px corner radius, a slate-to-near-black vertical gradient, a soft top sheen, a
  hairline inner border (so the edge holds on dark Docks), and the standard drop shadow.
- **Tiles:** the largest tile is warm coral (`#FF7A45`), "the biggest thing on your
  disk". The rest share a cool palette: teal `#14B8A6`, blue `#3B82F6`, indigo `#6366F1`
  and sky `#38BDF8`. Each tile has a small gap, rounded corners, a light top-to-bottom
  gradient, and a subtle shadow.
- **Small sizes:** at 64 px and below, edges snap to whole pixels and gaps are at least
  1 px. Shadows and highlights are dropped. At 16 px the 8% tile merges into its
  neighbor, leaving four clearly separated tiles.
- There is no text in the icon.

## Regenerating

Requires macOS with the Xcode command-line tools (`swift` and `iconutil`).

```sh
swift scripts/make-icon.swift Resources/AppIcon
```

The output directory defaults to `Resources/AppIcon`. Set `KEEP_ICONSET=1` to also keep
the individual PNG renders in `Resources/AppIcon/AppIcon.iconset/` for inspection (don't
commit that folder).

To change the design, edit the constants at the top of the script (`tiles`, colors,
`markInset`, `tileGap`, `tileCornerRadius`), rerun it, and commit the regenerated files.

To check the result:

```sh
iconutil -c iconset Resources/AppIcon/AppIcon.icns -o /tmp/check.iconset
sips -g pixelWidth /tmp/check.iconset/*.png
```

## Using it in the app bundle

Copy `AppIcon.icns` into `MacSize.app/Contents/Resources/` and set `CFBundleIconFile` to
`AppIcon` in `Info.plist`.
